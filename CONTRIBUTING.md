# Contributing to Seismic Sentinel CF

Thank you for your interest! This is an open-source project.

## How to Contribute

1. **Fork** the project (click the button at the top right on GitHub).
2. Create a **branch** for your change.
3. Apply your changes to the `index.html` file.
4. Open a **Pull Request** describing what you changed.

## Bug Reports or Ideas

Open an **Issue** on GitHub describing the problem or your idea as clearly as possible. If you have a screenshot, attach it.

## Development

The project is a single HTML file. You can edit it with any text editor (Notepad, Notepad++, VS Code, etc.). If you want to test it locally, open the `index.html` file in your browser (some features may require a local server to avoid CORS, but most features work locally as well).
